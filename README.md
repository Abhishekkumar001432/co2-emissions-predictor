# 🚗 Vehicle CO2 Emissions Predictor

[![Streamlit App](https://static.streamlit.io/badges/streamlit_badge_black_white.svg)](https://co2-emissions-predictor-your-app-name.streamlit.app)

> 🔗 **Live Demo:** [Click here to launch the web app](https://co2-emissions-predictor-your-app-name.streamlit.app)

An end-to-end Machine Learning web application that predicts vehicle CO2 emissions based on engine size, fuel consumption, and vehicle specifications. Built with Python, Scikit-Learn, and Streamlit.

---

## 📌 Project Overview
* **Goal:** Predict CO2 emissions ($\text{g/km}$) for light-duty vehicles.
* **Model:** Supervised Machine Learning Regressor.
* **Interface:** Interactive Streamlit Web Application.

---

## 🛠️ Tech Stack
* **Language:** Python
* **Libraries:** Pandas, NumPy, Scikit-Learn, Joblib, Streamlit
* **Deployment:** Streamlit Community Cloud
